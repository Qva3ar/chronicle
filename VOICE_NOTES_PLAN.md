# Voice Notes — План реализации

Голосовая заметка через AI: вторая FAB на главном экране → запись голоса →
облачная транскрипция и структуризация через AI (OpenAI/Gemini) → автоматическое
создание чистой заметки. Обработка переживает сворачивание приложения (WorkManager).

## Решения (согласовано)

- **STT**: облачная транскрипция через существующий AI-ключ пользователя (OpenAI Whisper
  или Gemini audio). Отдельного on-device STT нет.
- **Область (MVP)**: только создание заметок. Ни целей, ни рутин, ни todo, ни навигации.
- **AI чистит речь**: пользователь может мычать, «эээкать», запинаться — AI должен выдать
  связную, чистую заметку (убрать слова-паразcoды, оформить), а также заголовок и теги.
- **Без подтверждения**: заметка создаётся автоматически. Защита от ошибок — не блокирующий
  диалог, а лёгкий откат (см. «Обработка ошибок»).
- **Фон = вариант 1**: диктовка идёт в открытом приложении. После «Стоп» пользователь может
  свернуть приложение, а обработка (аудио → AI → заметка) продолжается в фоне через WorkManager.
  Запись микрофона в фоне (вариант 2) в MVP НЕ делаем.

## Архитектура / поток

```
[🎤 FAB] tap
  → запрос разрешения микрофона (permission_handler, уже в зависимостях)
  → запись аудио в файл во временную папку (пакет record)
  → UI состояния записи: пульсация + таймер + кнопки Стоп/Отмена
  → «Стоп»
     → файл сохранён, задача поставлена в WorkManager (durable)
     → UI сразу свободен, можно свернуть приложение
  → [фон] WorkManager task: VoiceNoteProcessor
     → загрузить ключ/модель из SharedPreferences (как insight generation)
     → провайдер == gemini ? один вызов : Whisper + chat (два вызова)
     → распарсить {title, text, tagIds}
     → RecordService.createRecord(row, tagIds)
     → local notification «Заметка создана 🎙️» (тап → открыть заметку)
     → удалить временный аудиофайл
```

Если приложение остаётся открытым к моменту готовности — дополнительно короткий
SnackBar с Undo (в дополнение к нотификации).

## Провайдеры

- **Gemini** (`google_generative_ai`, уже подключён): один `generateContent` с
  `DataPart('audio/m4a', bytes)` + промпт → сразу JSON `{title, text, tagIds}`.
  Дешевле и проще.
- **OpenAI** (`dart_openai`, уже подключён): шаг 1 `OpenAI.instance.audio.createTranscription(
  file, model: 'whisper-1')` → сырой транскрипт; шаг 2 `completeJson(...)` для чистки/структуры.

Выбор ветки — по `apiKeyOptions.firstWhere(value == model).provider` (как в `AiClient`).

## Промпт структуризации (общий смысл)

System: «Ты превращаешь спонтанную устную диктовку в чистую письменную заметку.
Убери слова-паразиты, повторы, самокоррекции ("нет, не так", "эээ"). Сохрани смысл и
детали. Верни ТОЛЬКО JSON без markdown: {"title": "...", "text": "...", "tagIds": [<int>...]}.
title — короткий; text — оформленный; tagIds — только из списка ниже, если явно уместны,
иначе []. Язык заметки = язык диктовки. Теги: <tagId:name; ...>».

Исходный распознанный текст (raw) сохраняем в text или в отдельное поле, чтобы при кривой
структуризации ничего не потерялось.

## Обработка ошибок (без блокирующего подтверждения)

- **Плохое распознавание / кривая структура** → заметка всё равно создаётся, raw-транскрипт
  сохранён; правится в один тап через нотификацию/SnackBar Undo.
- **AI-ошибка / нет ключа** → нотификация «Не удалось обработать голос», аудиофайл сохраняем
  (не удаляем), даём кнопку «Повторить». Не молчим.
- **Нет разрешения микрофона** → системный запрос; при отказе — подсказка открыть настройки.
- **Пустая/слишком короткая запись** → не отправляем в AI, тихо отменяем.
- **JSON парсинг** — переиспользовать/повторить логику `_parseIdsJson` из `workspace_ai_service`.

## Нюансы / риски

- **iOS + WorkManager**: iOS сильно ограничивает немедленные фоновые задачи — обработка
  может отложиться. Прагматика: запускать обработку сразу в приложении (foreground async)
  после «Стоп»; WorkManager — durable-фолбэк, если приложение свернули до завершения.
  (Android WorkManager отрабатывает быстро — как у insight generation.)
- Аудиофайл во временной директории, доступной фоновому изоляту; чистим после успеха.
- Формат аудио: m4a/aac (совместим с Whisper и Gemini), моно, умеренный битрейт — меньше upload.
- Ключ/модель в фоновом изоляте грузятся из SharedPreferences (прецедент: insight generation).
- Локаль: язык заметки определяет AI по языку речи; UI-строки — через существующий i18n.

## Порядок работ

1. Зависимость `record` + разрешения (Manifest/Info.plist) + `RECORD_AUDIO` runtime.
2. `AiClient.transcribeAndStructureNote` — обе ветки провайдеров + промпт.
3. `VoiceNoteService` — запись/стоп/файл + постановка задачи.
4. WorkManager `_handleVoiceNote` + `scheduleVoiceNote` + `TaskNames.voiceNote`.
5. Нотификация о готовности с открытием заметки по тапу.
6. UI: `VoiceRecordFab` + встраивание в `homepage.dart`, состояния записи.
7. Foreground-путь + SnackBar/Undo, когда экран открыт.
8. Локализация en/ru.
9. Тест: длинная сбивчивая диктовка; сворачивание после «Стоп»; отсутствие ключа; отказ в
   микрофоне; оффлайн (ошибка + повтор).

## Открытые вопросы (на потом, не блокируют MVP)

- Ограничение длины записи (напр. 2 мин) — экономия токенов/аудио.
- Показывать ли «сырой» транскрипт в заметке отдельным блоком, или только чистый текст.
- Нужен ли выбор языка вручную, или всегда авто по речи.
