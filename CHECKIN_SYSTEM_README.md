# Система чекинов (Check-in System)

## Обзор

Система ежедневных чекинов для отслеживания физического и эмоционального состояния, продуктивности и привычек. Чекины сохраняются как заметки и доступны для анализа в истории записей.

## Типы чекинов

### 🌅 Утренний чекин (Morning Check-in)
Выполняется после пробуждения для оценки качества сна и начального состояния.

**Метрики:**
- **Качество сна** (slider 1-10)
  - 1-3: Плохо спал, разбитость
  - 4-6: Нормально, но мог лучше
  - 7-10: Отлично выспался

- **Уровень энергии** (slider 1-10)
  - 1-3: Еле встал, хочется в кровать
  - 4-6: Средне, разгоняюсь
  - 7-10: Бодрый, полон сил

- **Настроение** (slider 1-10)
  - 1-3: Подавленность
  - 4-6: Нейтрально
  - 7-10: Хорошее, позитив

- **Уровень тревожности** (slider 1-10)
  - 1-3: Спокойствие
  - 4-6: Немного беспокоит
  - 7-10: Сильная тревога

### 🌙 Вечерний чекин (Evening Check-in)
Выполняется в конце дня для оценки прошедшего дня и активности.

**Метрики:**
- **Усталость** (slider 1-10)
  - 1-3: Полон сил
  - 4-6: Средняя усталость
  - 7-10: Истощение

- **Уровень стресса** (slider 1-10)
  - 1-3: Спокойно
  - 4-6: Ощутимое напряжение
  - 7-10: На пределе

- **Продуктивность** (slider 1-10)
  - 1-3: День впустую
  - 4-6: Базовые дела
  - 7-10: Очень продуктивно

- **Доволен днём** (slider 1-10)
  - 1-3: Хочу забыть
  - 4-6: Обычный день
  - 7-10: Отличный день

- **Достаточно воды** (slider 1-10)
  - 1-3: Почти не пил
  - 4-6: Меньше нормы
  - 7-10: Выпил норму

- **Потребление сахара** (slider 1-10)
  - 1: Совсем не ел сладкого
  - 2-4: Минимум (чай с сахаром)
  - 5-7: Умеренно (пара конфет, печенье)
  - 8-10: Много (торт, мороженое и т.д.)

- **Шаги** (number input)
  - Произвольное число шагов за день

- **Время на воздухе** (number input)
  - Количество минут, проведённых на свежем воздухе

- **Время в соц сетях** (number input)
  - Количество минут, проведённых в социальных сетях

## Функциональность

### Автоматические уведомления ⏰

Приложение отправляет **ежедневные уведомления** для напоминания о чекинах:

**Время по умолчанию:**
- 🌅 Утренний чекин: **9:00**
- 🌙 Вечерний чекин: **22:00**

**Настройка времени:**
- Drawer → "CHECKIN TIME SETTINGS"
- Выбрать время для утреннего и вечернего чекина
- Нажать "Сохранить"
- Уведомления автоматически переключатся на новое время

**При клике на уведомление:**
- Открывается соответствующий чекин-диалог
- Можно сразу заполнить метрики
- Быстрый доступ без открытия drawer

### Модальное окно чекина

Чекин открывается как **модальное окно (bottom sheet)** поверх текущего экрана, а не как отдельная страница. Это обеспечивает:
- Быстрый доступ без потери контекста
- Возможность закрыть свайпом вниз
- Плавную анимацию появления снизу
- Занимает 90% высоты экрана

### Основные возможности

#### 1. Заполнение чекина
- Slider-метрики: плавное изменение значения от 1 до 10
- Number-метрики: ввод произвольного числа (шаги, минуты)
- Иконка (?) для просмотра подсказок по каждой метрике
- Сохранение чекина создаёт заметку с типом `morning_checkin` или `evening_checkin`
- Закрытие: кнопка X или свайп вниз

#### 2. Режим редактирования (Edit Mode)
- Кнопка "Изменить" в AppBar активирует режим
- В каждой карточке метрики появляется иконка:
  - **Минус (-)** для видимых метрик → скрывает метрику
  - **Плюс (+)** для скрытых метрик → восстанавливает метрику
- Скрытые метрики отображаются внизу с opacity 0.4
- Конфигурация сохраняется в SharedPreferences

#### 3. Подсказки по шкале
- Нажатие на (?) открывает bottom sheet
- Показывает диапазоны значений с описаниями
- Помогает понять, какое значение выбрать

#### 4. Отображение в списке заметок
Чекины отображаются как специальные карточки:
- **Цвет фона:**
  - Утренний: тёплый оранжево-коричневый `Color.fromARGB(255, 90, 80, 60)`
  - Вечерний: холодный синий `Color.fromARGB(255, 60, 70, 90)`
- **Граница:**
  - Утренний: `MyColors.orangeDivider`
  - Вечерний: `MyColors.contactDivider`
- **Иконка:**
  - Утренний: ☀️ `Icons.wb_sunny`
  - Вечерний: 🌙 `Icons.nightlight`

### Data Flow

```
Drawer → "MORNING CHECKIN" или "EVENING CHECKIN"
    ↓
CheckinDialog.show(context, CheckinType)
    ↓
showModalBottomSheet() - открывает диалог снизу
    ↓
User Input → MetricCard → CheckinProvider.updateValue()
    ↓
CheckinProvider._values[key] = value
    ↓
User clicks "Сохранить"
    ↓
CheckinProvider.saveCheckin()
    ↓
CheckinRepository.saveCheckin()
    ↓
buildCheckinText() - форматирует текст
    ↓
DatabaseHelper.insertRecord() - сохраняет как заметку
    ↓
Record с типом morning_checkin или evening_checkin
    ↓
Navigator.pop() - закрывает диалог
```

### State Management

#### CheckinProvider
Управляет состоянием чекина:
- `_values: Map<String, int>` - значения метрик
- `_config: CheckinConfig` - конфигурация скрытых метрик
- `visibleMetrics` - видимые метрики
- `hiddenMetrics` - скрытые метрики
- `updateValue()` - обновление значения метрики
- `toggleMetricVisibility()` - скрыть/показать метрику
- `saveCheckin()` - сохранение в БД

#### EditModeProvider
Управляет режимом редактирования:
- `_isEditMode: bool` - текущее состояние
- `toggleEditMode()` - переключение режима
- `exitEditMode()` - выход из режима

## Формат сохранения

Чекины сохраняются как заметки (Record) с текстовым представлением:

### Пример утреннего чекина
```
Качество сна: 7
Уровень энергии: 8
Настроение: 6
Уровень тревожности: 3
```

### Пример вечернего чекина
```
Усталость: 5
Уровень стресса: 3
Продуктивность: 8
Доволен днём: 7
Достаточно воды: 6
Потребление сахара: 4
Шаги: 8450 шагов
Время на воздухе: 45 минут
Время в соц сетях: 120 минут
```

### Поля Record для чекина
```dart
Record(
  id: auto_increment,
  title: "Утренний чекин" или "Вечерний чекин",
  text: "Качество сна: 7\nУровень энергии: 8\n...",
  recordType: RecordType.morningCheckin или RecordType.eveningCheckin,
  createdAt: timestamp,
  tagIds: [],
  goalId: null,
  routineId: null,
  isLocked: false,
)
```

## Использование

### Для пользователя

1. **Настроить время уведомлений** (первый запуск, опционально)
   - Открыть drawer (☰)
   - Выбрать "CHECKIN TIME SETTINGS"
   - Нажать на карточку утреннего или вечернего чекина
   - Выбрать желаемое время в диалоге
   - Нажать "Сохранить"
   - Уведомления будут приходить в установленное время

2. **Открыть чекин**
   - **Вариант А**: Нажать на уведомление в установленное время
   - **Вариант Б**: Открыть drawer (☰) и выбрать "MORNING CHECKIN" ☀️ или "EVENING CHECKIN" 🌙
   - Модальное окно появится снизу экрана

3. **Заполнить метрики**
   - Двигать слайдеры для оценки состояния
   - Ввести числа для шагов и времени на воздухе
   - Нажать (?) для просмотра подсказок

4. **Настроить видимость метрик** (опционально)
   - Нажать "Изменить"
   - Нажать (-) чтобы скрыть ненужную метрику
   - Нажать (+) чтобы вернуть метрику
   - Нажать "Готово"

5. **Сохранить**
   - Нажать "Сохранить"
   - Чекин появится в списке заметок
   - Диалог автоматически закроется

6. **Закрыть без сохранения**
   - Нажать X в верхнем левом углу
   - Или свайпнуть диалог вниз
   - Или нажать на затемнённую область вокруг диалога

7. **Просмотр истории**
   - Чекины отображаются в списке заметок с цветными карточками
   - Можно фильтровать по тегам
   - Можно искать по тексту

### Для разработчика

#### Открытие чекина программно

```dart
// Открыть утренний чекин
CheckinDialog.show(context, CheckinType.morning);

// Открыть вечерний чекин
CheckinDialog.show(context, CheckinType.evening);
```

#### Кастомизация модального окна

Настройки модального окна находятся в `checkin_dialog.dart`:
```dart
showModalBottomSheet(
  context: context,
  isScrollControlled: true,        // Позволяет контролировать высоту
  backgroundColor: Colors.transparent,  // Прозрачный фон для скруглённых углов
  builder: (context) => Container(
    height: screenHeight * 0.9,   // 90% высоты экрана
    decoration: BoxDecoration(
      color: bgColor,
      borderRadius: BorderRadius.vertical(
        top: Radius.circular(20),  // Скруглённые верхние углы
      ),
    ),
    // ...
  ),
);
```

#### Добавление новой метрики

1. Открыть `morning_metrics.dart` или `evening_metrics.dart`
2. Добавить новую константу:
```dart
static const CheckinMetric myMetric = CheckinMetric(
  key: 'my_metric',
  label: 'Моя метрика',
  inputType: MetricInputType.slider,
  hints: [
    HintRange(min: 1, max: 3, description: 'Плохо'),
    HintRange(min: 4, max: 6, description: 'Средне'),
    HintRange(min: 7, max: 10, description: 'Отлично'),
  ],
);
```
3. Добавить в список `all`:
```dart
static const List<CheckinMetric> all = [
  sleepQuality,
  energyLevel,
  myMetric, // <-- новая метрика
];
```

#### Изменение типов записей

Enum `RecordType` находится в `lib/models/record_type.dart`:
```dart
enum RecordType {
  regular,
  routine,
  goal,
  morningCheckin,
  eveningCheckin,
}
```

Добавление нового типа:
1. Добавить в enum
2. Обновить `toDbValue()` и `recordTypeFromDbValue()`
3. Обновить `RecordListItem` для отображения нового типа

## Технические детали

### Зависимости
- `provider: ^6.1.5` - state management
- `shared_preferences: ^2.2.2` - сохранение конфигурации
- `sqflite: ^2.0.1` - база данных
- `intl: ^0.19.0` - форматирование даты/времени

### База данных
Чекины используют существующую таблицу `record`:
- Поле `record_type` содержит 'morning_checkin' или 'evening_checkin'
- Поле `text` содержит форматированный текст метрик
- Поле `title` содержит "Утренний чекин" или "Вечерний чекин"

### SharedPreferences

**Конфигурация скрытых метрик** (ключ `checkin_config`):
```json
{
  "hiddenMorningMetrics": ["anxiety_level"],
  "hiddenEveningMetrics": ["water_intake", "outdoor_minutes"]
}
```

**Время уведомлений:**
- `checkin_morning_time`: "09:00" (по умолчанию)
- `checkin_evening_time`: "22:00" (по умолчанию)

### Система уведомлений

**Notification Service** (`lib/services/notification_service.dart`):
- Создаёт отдельный канал `checkin_channel` для чекин-уведомлений
- Планирует ежедневные уведомления с использованием `zonedSchedule()`
- Использует `matchDateTimeComponents: DateTimeComponents.time` для повторения каждый день
- Обрабатывает клики на уведомления через `_handleNotificationTap()`

**Notification IDs:**
- Утренний чекин: `3000`
- Вечерний чекин: `3001`

**Payload формат:**
- `checkin_morning` - открывает утренний чекин
- `checkin_evening` - открывает вечерний чекин

**Инициализация:**
```dart
// В main.dart при старте приложения
await NotificationService().initialize();
await NotificationService().scheduleCheckinNotifications();
```

**Переназначение после изменения времени:**
```dart
// Автоматически вызывается при сохранении настроек
await NotificationService().rescheduleCheckinNotifications();
```

## UI/UX особенности

### Модальное окно
- **Высота**: 90% экрана для комфортного заполнения
- **Handle bar**: полоска вверху для визуального указания на возможность закрытия свайпом
- **Скруглённые углы**: 20px radius для современного вида
- **Затемнённый фон**: полупрозрачный чёрный фон за диалогом
- **Анимация**: плавное появление снизу

### Закрытие диалога
Пользователь может закрыть диалог 3 способами:
1. Нажать X в заголовке
2. Свайпнуть диалог вниз (gesture)
3. Нажать на затемнённую область вокруг диалога

### Сохранение контекста
Модальное окно не прерывает работу с приложением:
- Пользователь видит затемнённый экран под диалогом
- При закрытии возвращается к тому же месту
- Drawer закрывается автоматически перед открытием диалога

## Известные ограничения

1. **Редактирование чекинов**: Сохранённые чекины можно редактировать только как обычную заметку (текст)
2. **Один чекин в день**: Система не ограничивает создание нескольких чекинов одного типа за день
3. **Парсинг**: При просмотре чекина в списке он отображается как текст, а не как карточки метрик
4. **Полноэкранный режим**: `CheckinScreen` (полноэкранный вариант) помечен как deprecated, используется только `CheckinDialog`

## Troubleshooting

### Чекин не сохраняется
- Проверить логи: `log('Error saving checkin: $e')`
- Убедиться, что база данных инициализирована
- Проверить права доступа к БД

### Конфигурация не сохраняется
- Проверить доступ к SharedPreferences
- Очистить кэш приложения: Settings → Apps → Chrono → Clear Data

### Метрики не скрываются
- Перезапустить экран чекина
- Проверить логи `CheckinConfigRepository`
- Удалить ключ `checkin_config` из SharedPreferences
