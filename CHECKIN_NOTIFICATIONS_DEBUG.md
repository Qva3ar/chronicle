# Отладка уведомлений чекинов

## Быстрая диагностика

### Шаг 1: Запустите тестовое приложение

```bash
flutter run test_checkin_notifications.dart
```

Нажмите кнопки в следующем порядке:

1. **"🔔 Тест: показать уведомление СЕЙЧАС"** - должно появиться уведомление мгновенно
   - ✅ Если появилось → система уведомлений работает, переходите к шагу 2
   - ❌ Если НЕ появилось → проблема с разрешениями, см. "Проверка разрешений" ниже

2. **"🔍 Полный тест"** - проверит настройки и планирование
   - Смотрите логи в приложении
   - Должно показать время утреннего и вечернего чекина

3. **"📋 Список запланированных"** - покажет все запланированные уведомления
   - Должно быть минимум 2 уведомления: checkin_morning и checkin_evening
   - ❌ Если список пустой → см. "Проблема: уведомления не планируются"

### Шаг 2: Проверьте логи при запуске основного приложения

```bash
flutter run | grep -i "checkin"
```

Должны увидеть:
```
Scheduling checkin notifications...
✅ Scheduled checkin notifications: Morning 9:0, Evening 22:0
Checkin notifications scheduled
```

## Частые проблемы и решения

### Проблема 1: Уведомления заблокированы в системе

**Android:**
1. Откройте **Настройки** → **Приложения** → **Chrono**
2. Нажмите **Уведомления**
3. Убедитесь что:
   - ✅ Уведомления включены
   - ✅ Канал "Daily Checkin Notifications" включен
   - ✅ Приоритет установлен на "Высокий" или "Срочный"

**MIUI (Xiaomi):**
1. Откройте **Настройки** → **Приложения** → **Управление приложениями** → **Chrono**
2. **Автозапуск**: ВКЛ
3. **Уведомления**: ВКЛ
4. **Разрешения** → **Уведомления**: ВКЛ
5. **Режим энергосбережения**: Нет ограничений
6. **Блокировка в фоне**: ВЫКЛ

### Проблема 2: Время уведомления уже прошло сегодня

Уведомления планируются на следующий день, если время уже прошло.

**Решение:**
1. Зайдите в приложение → Drawer → **CHECKIN TIME SETTINGS**
2. Установите время на **ближайшие 2-3 минуты**
3. Нажмите **Сохранить**
4. Ждите 2-3 минуты
5. Должно прийти уведомление

### Проблема 3: Уведомления не планируются

**Проверка:**
```bash
# Смотрите логи при запуске
flutter run | grep -E "(Scheduling checkin|Error scheduling)"
```

Если видите ошибку:
```
❌ Error scheduling checkin notifications: ...
```

**Возможные причины:**
- SharedPreferences не инициализирован
- Нет прав на точные уведомления (Android 12+)

**Решение:**
1. Удалите приложение полностью
2. Переустановите: `flutter run`
3. При первом запуске разрешите все запрашиваемые права

### Проблема 4: Уведомления планируются, но не показываются

**Проверка:**
```dart
// В тестовом приложении нажмите "📋 Список запланированных"
// Должно показать:
📋 Всего запланировано: 2 (или больше)
  - ID 3000: Утренний чекин (checkin_morning)
  - ID 3001: Вечерний чекин (checkin_evening)
```

Если уведомления в списке есть, но не показываются:
- **DND (Не беспокоить)** может блокировать
- **Фоновая активность** ограничена
- **Оптимизация батареи** включена

**Решение для Android:**
```
Настройки → Батарея → Оптимизация батареи → Chrono → Не оптимизировать
```

## Проверка вручную через adb

### Список запланированных уведомлений:

```bash
adb shell dumpsys notification | grep -A 20 "chrono"
```

### Права на точные уведомления:

```bash
adb shell dumpsys package com.example.chrono | grep -A 5 "permission"
```

### Принудительная отправка тестового уведомления:

Запустите тестовое приложение и нажмите "🔔 Тест: показать уведомление СЕЙЧАС"

## Временное решение: Ручная установка времени

Если автоматические уведомления не работают:

1. Установите время чекина на **следующие 2 минуты**
2. Дождитесь уведомления
3. После успешного теста верните нужное время

## Известные ограничения

### Android 12+ (API 31+)
- Требуется разрешение `SCHEDULE_EXACT_ALARM`
- Пользователь должен вручную разрешить в настройках

### MIUI/ColorOS/OneUI
- Агрессивное управление батареей
- Требуется отключить оптимизацию для Chrono
- См. [MIUI_SETUP_GUIDE.md](MIUI_SETUP_GUIDE.md)

3. Скопируйте все логи
4. Откройте issue в репозитории с логами
